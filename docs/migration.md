# アプリケーションの移行と切り戻し

> [!IMPORTANT]
> これは将来、移行を実施する場合の手順である。2026-08-18時点では移行を行わず、
> `sudachi-sparse-v1`のローカル実装とgolden vectorだけを確定仕様へ更新している。

## 移行順序

1. 各アプリケーションで`rakuhoku`のGitコミットまたはリリースタグを固定する。
2. 既存の設定とsingletonの接続方法を維持したまま、アプリケーション内のdense encoderを
   共通パッケージへ置き換える。
3. 各アプリケーションの代表的な入力で、dense出力の互換性を確認する。
4. Qdrantアダプターを介して、アプリケーション内のsparse encoderを置き換える。
5. 名前に`sudachi-sparse-v1`を含む新しいコレクションを作成し、疎ベクトルへ
   `Modifier.IDF`を設定する。
6. 全文書を再インデックスする。新旧の疎ベクトルを同じコレクションへ混在させない。
7. 短いクエリ、固有名詞、表記揺れ、同義語、部分一致、OCR誤り、文書長による偏りについて、
   Recall@K、MRR、NDCG@K、上位K件の非関連率を比較する。
8. 評価結果を確認した後で、アプリケーションの設定を新コレクションへ切り替える。
9. 切り替え後の動作が安定してから、各アプリケーション内の旧encoderと旧コレクションを
   削除する。

入力テキストの組み立てはアプリケーション側に残す。特に`dxsympo`のmetadata経路と
scene経路、およびそれぞれの集約処理は分離したまま維持する。

## 切り戻し

評価中は、旧コレクションとその設定項目を保持する。切り戻す場合は、アプリケーション設定の
コレクション名とベクトル名を旧設定へ戻し、アプリケーションを再起動する。

既存コレクションをその場で変換しないため、切り戻し時の再インデックスは不要である。
旧実装を削除するまでは、使用したパッケージバージョンとコレクションの対応を配備記録へ残す。
